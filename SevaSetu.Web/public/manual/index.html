AaoSaharaBane

A guide for the family, caregiver, agency, hospital coordinator, and admin. परिवार, केयरगिवर, एजेंसी, अस्पताल और एडमिन के लिए।

Open this page from Help in the app. AaoSaharaBane is a bridge of care for home nursing and elder care in India. One care episode is the spine: one elder, one home, visits, logs, and bills.

It is not PhysioCard (clinic session cards). Cash and UPI are only a record. No fee is collected inside the app.

What the app does not do जो ऐप नहीं करता

  • It does not collect UPI or card money.
  • It does not show a live map of the caregiver.
  • It is a website, not a separate iPhone or Android app.
  • WhatsApp reminders send only when Cloud API keys are set. If they are empty, the reminder is skipped and booking still works.
  • The elder light home is SOS and “I am ok” only. The family and the assigned caregiver own the chart.

Sign in लॉग इन

  1. Open the site and enter the email or mobile, then the password.
  2. New users tap Register and choose Family, Independent caregiver, Agency, or Hospital coordinator.
  3. A new independent caregiver stays hidden from Find until admin KYC is Passed.

Family — Home परिवार — होम

  1. Add an elder: name, age, address. Health-data consent is required.
  2. The list shows elders. SOS records an alert for that elder.
  3. Open an episode to see the log, vitals, shifts, and bills for that home.

Family — Find देखभाल खोजें

  1. Choose the elder.
  2. KYC-passed independent caregivers show city and hourly rate. Request asks them to accept. Instant book books an 8-hour slot starting in about three hours if the calendar is free.
  3. Request agency sends the job to an agency desk to assign staff.

Family — Bills बिल

  1. The list shows issued invoices. Amounts are frozen when the bill is issued. Changing a rate later does not rewrite that bill.
  2. If GST is off, the bill says no tax is charged. If GST is on, it is a tax invoice with the snapshotted GSTIN.
  3. Opt out of WhatsApp stops visit reminders for this login.
  4. Export my data downloads a JSON copy of elders, episodes, and logs.
  5. On the episode desk, Mark UPI (or Cash) records payment. It does not collect money.

Episode desk एपिसोड

Family and caregiver open the same episode. Comfort for today is 1–10; a second save the same India day updates the same row.

  1. Save log stores comfort. Optional meals, mobility, and a short note sit on that day.
  2. ADL bathing ticks an activity with a time. MAR given records a medicine line. Incident flags a fall or other event for the family.
  3. Last 14 days of logs and vitals (BP and the rest) appear as a list.
  4. Shifts: Check in, Out, or No-show. Overlapping check-in is refused.
  5. Wound / ID photo stores the file in blob storage (or a local folder if Blob is empty). Bytes are not kept in SQL.
  6. After 7 days of care, the family can Rate this care (1–5 stars). One rating per episode in this version.
  7. Issue invoice bills hours × the rate copied at that moment.

Caregiver — Shifts and Jobs केयरगिवर

  1. Shifts lists your slots. Open episode to write the log and check in.
  2. Block leave marks a calendar block so instant book will skip that window.
  3. ID photo and GST sit on this login. GST on means later invoices can be tax invoices without SQL edits.
  4. Jobs is the request inbox. Accept or Decline. KYC must be Passed before you can accept work.

Agency — Desk and Inbox एजेंसी

  1. Desk shows hours rostered against hours billed, and staff by name and KYC.
  2. Inbox: pick a staff name, then Accept. Decline closes the request.
  3. Replace on the desk picks a staff name for a shift. The family still sees one episode.
  4. Branches and Consumables are recorded on the desk. GST is a separate tab.

Hospital — Discharge अस्पताल

  1. Enter the elder id, diagnosis, and meds. Save packet attaches the hospital to that episode.
  2. The visit board is read-only for elders discharged from this hospital. This is not a full hospital system.

Admin — KYC and Audit एडमिन

  1. Pass puts the caregiver on Find. Fail keeps them hidden and stores a reason.
  2. Audit lists who opened an elder chart (episode.open) and similar actions.

Reminders रिमाइंडर

A worker checks every five minutes for booked shifts about one hour away. WhatsApp uses the Cloud API template name in App Service (default sevasetu_visit_reminder). Empty token = reminder skipped; booking still works. Family opt-out is honoured.

Family or elder can tap Enable visit alerts. Web push uses VAPID keys set on App Service, never committed. Empty keys = push skipped.

Elder — light home बुजुर्ग

SOS and I am ok only. There is no chart, no bills, and no Find. Hindi/English is the same toggle as other roles (हिन्दी in the header).
